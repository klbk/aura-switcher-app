# Contributing

Thanks for helping! Bugs, translations and small fixes are all welcome.

## Build
- macOS: `./build.sh` (needs Xcode command line tools).
- Windows: `windows/build.sh` (cross-built on Mac with Zig).
- Linux: `linux/build.sh` (on Linux; packages and keyboard access — [docs/linux.md](docs/linux.md)).

## Tests
Run `tests/run.sh` after any change to `engine.swift`. It compares results with `tests/baseline-*.txt`; if results change on purpose, run with `--update` and explain the change in the PR. The Windows and Linux engines have the same test: `tests/run-windows.sh`, `tests/run-linux.sh`.

## Translations
Proofreading of the menu and site texts is the easiest way to help — see [issue #6](https://github.com/klbk/aura-switcher-app/issues/6) and the templates in `translations/`. Menu strings are generated by `tools/menu_i18n.py` — edit it, not the generated blocks.

## Pull requests
Keep them small and focused, one change per PR. Don't put private data (paths, emails, tokens, text you typed) in code, logs or screenshots. By contributing you agree your work is licensed under GPL-3.0.

Be kind: see the [Code of Conduct](CODE_OF_CONDUCT.md).
