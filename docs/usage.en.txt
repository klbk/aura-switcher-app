HOW TO USE
• Typed a word in the wrong layout — press Space, AURA Switcher fixes it.
• Press Shift twice quickly (either side) — the last word or the selected text
  is converted to another layout. The key can be changed in the menu
  ("Correction key": Ctrl, Option/Alt or off); Shift is the safest choice.
• Enter is never held back: the word before Enter is not corrected (Space and
  double Shift work as usual).
• Click the language code in the menu bar (EN, УК, РУ) for the menu: turn off,
  sound, exclude apps, language per app, my words, menu language.
• AURA pauses itself in games, game chat included: double Shift is often sprint
  there. A game AURA didn't recognise can be excluded after leaving it:
  menu → "Don't work in (recent apps)".
• Updates: menu → "Check for updates…" (a page in your browser tells whether
  there is a new version and how to update).
  After a month a reminder dot appears next to the language code. AURA itself never goes online.
• Quit: menu → "Quit". AURA Switcher starts at login (can be turned off in the menu).
