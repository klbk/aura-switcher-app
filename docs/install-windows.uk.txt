AURA Switcher 0.6.1 (бета) — українська розробка 🇺🇦
Сама виправляє текст, набраний не в тій розкладці: ghbdsn → привіт.
Windows 10 або 11.

ВСТАНОВЛЕННЯ
1. Розпакуйте архів (правою кнопкою → «Видобути все»).
2. Відкрийте «AURA Switcher.exe». Якщо з'явиться «Windows захистила ваш ПК» —
   «Докладніше» → «Усе одно запустити» (програма ще не підписана).
3. Біля годинника (можливо під стрілочкою ^) з'явиться код мови: EN, УК…

ЯК КОРИСТУВАТИСЯ
• Набрали слово не в тій розкладці — натисніть пробіл, AURA Switcher виправить.
• Двічі швидко натисніть Shift — останнє слово або виділений текст
  перекладеться в іншу розкладку.
• Клік по коду мови в треї — меню: вимкнути, звук, винятки, мова для програми,
  слова-винятки, мова меню.
• Закрити: меню → «Вихід». Запускається сама при вході в Windows.
